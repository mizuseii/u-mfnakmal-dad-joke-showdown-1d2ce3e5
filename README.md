# Dad Joke Showdown

One dad joke, 85 characters, for [make.fun](https://make.fun/bounty/u-mfnakmal-dad-joke-showdown-1d2ce3e5)'s
"Dad Joke Showdown" bounty ($5 in USDC).

> Dad's grill has two settings: medium-rare for the steaks and well-done for his jokes.

A dad at the barbecue, one clean pun — "well-done" does double duty for the
meat and the humour — setup and punchline in a single breath, punchline at
the very end. Original wording, no stock joke, nothing explained.

## Run it

```sh
node main.ts
```

It writes the joke to `/output/entry.txt` (creating `/output` if needed).
Deterministic, no network, no secrets — the line is a plain string literal in
`main.ts`.
